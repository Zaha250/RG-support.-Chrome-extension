# RG Support

Расширение для Google Chrome, которое помогает сотрудникам технической поддержки отвечать на типовые обращения и находить пользователей в диспетчерской системе. Проект использует Manifest V3, JavaScript, HTML и CSS, без сборщика и сторонних JavaScript-зависимостей.

## Возможности

- Просмотр готовых ответов из локальной базы шаблонов.
- Поиск по тексту шаблонов сразу при вводе
- Копирование выбранного ответа в буфер обмена.
- Поиск пользователя по логину из открытого письма с помощью горячей клавиши.
- Поиск по выделенному тексту через контекстное меню.

В интерфейсе также предусмотрена кнопка прямой вставки шаблона. Её текущая реализация требует доработки; для вставки ответа используйте копирование и стандартную команду вставки браузера.

## Установка

1. Скачайте проект или клонируйте репозиторий.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите корневую папку проекта, в которой находится `manifest.json`.
6. При необходимости закрепите **RG Support** на панели расширений.

Установка npm-пакетов и запуск локального сервера не требуются. После изменения файлов нажмите кнопку обновления расширения на странице `chrome://extensions` и заново откройте его окно.

## Работа с шаблонами

1. Нажмите значок расширения.
2. Введите часть текста ответа в поле **Поиск по шаблонам**.
3. Нажмите **Копировать** у подходящего шаблона.
4. Перейдите в поле ответа и вставьте текст через `Ctrl+V` или `Command+V` на macOS.

Поиск проверяет вхождение введённой фразы в текст шаблона. При отсутствии совпадений отображается сообщение «Шаблоны не найдены». Очистка поля возвращает полный список.

## Поиск пользователя

### Горячая клавиша

Откройте письмо с обращением и нажмите:

| Система | Сочетание по умолчанию |
| --- | --- |
| Windows / Linux | `Ctrl+Shift+S` |
| macOS | `Command+Shift+S` |


```text
https://<домен-клиента>/demo/dispetcher/users/?q=<логин-в-URL-кодировке>
```

### Контекстное меню

Выделите нужный логин или другой поисковый текст в письме, нажмите правую кнопку мыши и выберите **Найти пользователя «…»**. В качестве запроса будет использован выделенный текст. Ссылка отписки с доменом клиента по-прежнему должна присутствовать в письме.

### Если поиск не срабатывает

- Проверьте назначение сочетания на странице `chrome://extensions/shortcuts`: оно может быть не назначено или занято другой командой.
- Убедитесь, что открыто письмо со строкой «Логин заявителя:» и ссылкой отписки. Для поиска через контекстное меню строка логина не требуется.
- Проверьте, что расширению разрешён доступ к странице с письмом.
- На странице `chrome://extensions` откройте инструменты разработчика фонового обработчика (**service worker**) расширения и повторите действие. Причина ошибки будет выведена в консоль.

## Добавление и изменение шаблонов

База ответов хранится в `db/templates.json` — это массив объектов с числовым идентификатором `id` и строкой `content`:

```json
[
  {
    "id": 100,
    "content": "Здравствуйте.\nТекст ответа на типовой вопрос."
  }
]
```

Добавляйте новые объекты в существующий массив и назначайте им уникальные идентификаторы. Выбор шаблона для копирования выполняется по `id`, поэтому повторяющиеся значения могут привести к копированию другого ответа. Порядок объектов в файле определяет порядок шаблонов в окне расширения.

Сохраняйте корректный JSON: двойные кавычки для строк, `\n` для переносов и отсутствие запятой после последнего элемента. После редактирования обновите расширение.

## Разрешения

| Разрешение | Назначение |
| --- | --- |
| `scripting` | Выполнение кода на странице для чтения письма и работы с редактором |
| `activeTab` | Доступ к активной вкладке по действию пользователя |
| `contextMenus` | Пункт поиска по выделенному тексту |
| `<all_urls>` в `host_permissions` | Доступ к страницам и их фреймам на разных доменах |

Шаблоны поставляются вместе с расширением. Поиск шаблонов выполняется локально; поиск пользователя открывает страницу диспетчерской системы и передаёт запрос в параметре `q`. Окно расширения подключает шрифт Inter через Google Fonts.
